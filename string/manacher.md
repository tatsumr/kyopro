# Manacher

## 概要
長さ $N$ の文字列 $S$ が与えられたときに、各 $i$ について「 $i$ 文字目を中心とする最長の回文の半径の長さ」を得ることが出来る。

偶数長の回文についても知りたい時は、 `S = "$a$a$a$a$a$"` のようにするとよい。このとき、 `S[i]` を中心とする最長の回文の**直径+1**が返ってくる。

## 使用例
- "aaaaaa" のときの返り値は `{1, 2, 3, 3, 2, 1}` 。
  - 一般に、返ってくる配列を $r$ とすると $S[i - r[i] + 1]$ から $S[i + r[i] - 1]$ の長さ $2r[i] - 1$ の文字列が $i$ 文字目の最長回文。
- "abba" のときの返り値は `{1, 1, 1, 1}` 。
- "$a$b$b$a$" のときの返り値は `{1, 2, 1, 2, 5, 2, 1, 2, 1}` 。
  - （0-indexed で) 4 番目の '$' に対応する「 $5$ 」は、「回文 "abba" の長さ + 1」を表している。
