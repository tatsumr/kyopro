# Manacher

## 概要
長さ $N$ の文字列 $S$ が与えられたときに、各 $i$ について「 $i$ 文字目を中心とする最長の回文の半径の長さ」を得ることが出来る。

## 使用例
- `S = "aaaaa"` のときの返り値は `{1, 2, 3, 2, 1}` である。
- 偶数長の回文も含めた最長の回文の長さを知りたい時は `S = "$a$a$a$a$a$"` のようにすると、 `S[i]` を中心とする最長の回文の**直径の長さ+1**が返ってくる。
  - `"$a$a$a$a$a$"` の返り値（ `$` は除く）は `{2, 4, 6, 4, 2}` である。
