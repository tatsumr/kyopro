# Interval Set の実装の解説

## insert
`insert(l, r, x)` のアルゴリズムを解説する。

### 1. スタート地点を探す
左端が `l` 以下の区間のうち、最も右にあるものを探す。要は「 `[l, r)` と被っているかもしれない区間のうち、最も左にあるもの」である。実際は区間そのものではなくイテレータを取得する。このスタート地点となるイテレータを `it` とする。
```cpp
auto it = prev(s.upper_bound({l, SINF, e}));
```

### 2a. `it` が `[l, r)` を完全に含んでいるとき
```
it         [L---------------------R)
挿入したい        [l-----r)
```
- 両者の値が同じ場合は、何もしなくてよい。このまま **3** の調整へ移る。
- 異なる場合は一旦 `it` を削除し、`[L, l)`、`[l, r)`、`[r, R)` を挿入する。その後 **3** へ。
  - （注意）区間を挿入するのはそれぞれ $L < l$、 $l < r$ 、 $r < R$ の場合。以後明示しないが、区間 `[left, right)` を実際に挿入するのは `left` < `right` の場合であることに注意されたい。

### 2b. `it` が `[l, r)` を完全に含んでいないとき
次のような方針で処理する。
1. 区間の左端を調整する（**2b.1**）。
2. `[l, r)` が完全に含んでいる区間をひたすら削除する（**2b.2**）。
3. 区間の右端を調整する（**2b.3**）。
4.  `[l, r)` を挿入する（**2b.4**）。
```
set の中身   [---)   [---) [----------) [-----)    [-----)
挿入したい     [l-------------------------------------r)

             <--->  <------------------------>    <------>
            （調整）    （ひたすら消す）　　　　　　  （調整）　
```

#### 2b.1. 左端の調整
##### 2b.1.1. `it` と `[l, r)` が被っているとき
1. 現在 `it` が指している区間 `[L, R)` を削除する。
2. `it` を 1 つ進める。
3. `[l, r)` を伸ばして `[L, r)` とする or `[L, l)` を挿入する。

【`it` と `[l, r)` の値が同じとき】
```
set の中身   [L--- it --R)  [----)         （削除）  [--- it ---)
挿入したい       [l------------       =>    [l=L------------------
```

【`it` と `[l, r)` の値が異なるとき】
```
set の中身   [L~~~ it ~~~~R)  [----)        [L~~l)    [--- it ---)
挿入したい       [l------------       =>          [l---------------
```

##### 2b.1.2. `it` と `[l, r)` が被っていないとき
`it` を 1 つ進める。
```
set の中身    [-- it --)     [-------)        [--------)     [-- it --)
挿入したい                [l----------   =>               [l----------
```

#### 2b.2. ひたすら削除
`it->r` $\leq$ `r` が成り立つ間、 `it` が指している区間を削除して `it` を 1 つ進める。

#### 2b.3. 右端の調整
**2b.1**と同様の処理をする。
##### 2b.3.1. `it` と `[l, r)` が被っているとき
1. 現在 `it` が指している区間 `[L, R)` を削除する。
2. `[l, r)` を伸ばして `[l, R)` とする or `[r, R)` を挿入する。

【`it` と `[l, r)` の値が同じとき】
```
set の中身   [L--- it ----R)                （削除）  
挿入したい   --------r)               =>    --------r=R)
```

【`it` と `[l, r)` の値が異なるとき】
```
set の中身   [L~~~ it ~~~~R)                     [r~~~R)    
挿入したい   --------r)               =>    ----r)
```

##### 2b.3.2. `it` と `[l, r)` が被っていないとき
何もしない。
```
set の中身           [-- it -- )
挿入したい   ----r)                  
```
